Mandate

AI code review on every commit. Type-checked pipelines that catch security issues before they reach your repo.

$ pip install mandate-lang

$ mandate hook install

What happens when you commit

$ git commit -m "add admin endpoint"

analyze_diff
  change_type: feature
  complexity: simple
  summary: Added an admin route to execute shell commands.
  verify: 4/4 passed

scan_security
  issues_found: 3
  severity: critical
  findings:
    - Hardcoded secret: API key found.
    - Command injection via unsanitized input.
    - Missing input validation for command execution.
  verify: 2/2 passed

generate_review
  verdict: request_changes
  risk_level: high
  suggestions:
    - Remove hardcoded API key, use environment variables.
    - Sanitize input to prevent command injection.
    - Use subprocess with proper arguments.
  verify: 4/4 passed

Pipeline complete: 3 stages, all passed.

Type-Checked Pipelines

mandate check verifies that stage outputs match downstream inputs at compile time. Catch mismatches before spending LLM tokens.

Static Analysis

mandate analyze reports token cost, verify coverage, dead stages, and dependency graphs. Whole-program analysis no Python framework can do.

Test Without LLM

mandate test --pipeline runs the full pipeline with mock providers. CI-friendly, no API key, deterministic.

Budget Enforcement

budget { max_calls: 1 } per stage. The analyzer catches violations before execution. No runaway LLM costs.

Import System

import scan from "./scanner.mdt" composes mandates across files. Build libraries of reusable AI workflow stages.

Any LLM

Works with OpenAI, Ollama, vLLM, or any OpenAI-compatible API. Not locked to a provider.

The Language

Each pipeline stage is a .mdt file with typed inputs, LLM synthesis blocks, and verification assertions.

mandate scan_security {
  intent: "Scan a diff for security issues"

  input:  { diff: string, file_path: string }
  output: { issues_found: int, severity: string, findings: string }

  budget { max_calls: 1 }

  flow {
    scan = synthesize {
      given: input.diff, input.file_path
      produce: { issues_found: int, severity: string, findings: string }
      instruction: "Scan for secrets, injection, XSS, path traversal..."
    }
    return { issues_found: scan.issues_found, severity: scan.severity, findings: scan.findings }
  }

  verify {
    output.issues_found >= 0
    output.findings.length > 0
  }
}
